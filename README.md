# 学术论文协作审阅台

面向作者、审稿人与编辑三类角色的论文协作审阅前端。正文、批注、讨论、建议、版本和冲突处理数据均保存在浏览器本地。

## 功能

- 三个独立工作区：
  - 作者可直接修改正文，逐条接受或拒绝审稿人的修改建议。
  - 审稿人可引用原文、添加段落批注、提出修改建议并回复讨论。
  - 编辑可合并同一段落的重复意见、锁定已确认段落并比较两个版本。
- **投审对账台（按投稿编号 `MS-2026-0417`）**：把投审系统里每轮评审的决定、截止时间与随附意见并入工作台台账。
  - 同一个回合两边都动过时，**正文与批注的处置按工作台**，**决定与截止时间按投审系统**；对不上的字段红框圈出，并保留工作台邮件原值对照。
  - 投审系统那轮已结束、工作台还压着未处理意见的回合，会在顶部与对账台标出，由编辑**逐个定夺**：继续在本回合处理 / 转入下一轮 / 随回合收口关闭。
  - 对账失败时先按工作台侧重试（3 次），失败后降级为工作台优先、未对成账的回合挂起；投审系统恢复后只补没送成的回合。
  - 回执以稳定的 `receiptId` 去重，同一份回执再拉一次只就地刷新，不会多出回合。对账台提供“模拟故障 / 恢复并出新回执”按钮演示整条链路。
- 侧边目录、段落高亮、批注过滤、修订模式与版本差异表。
- `J` / `K` 在段落之间导航，`T` 切换修订模式，编辑角色可用 `L` 锁定或解锁段落；`Ctrl/⌘ + Z` 撤销，`Ctrl/⌘ + Y` 或 `Shift + Z` 重做。
- 完整撤销重做、手动保存和浏览器未保存提醒。
- 草稿自动写入 `localStorage`（含回合台账与对账状态），刷新或断网后仍可继续。
- 内置模拟接口。点击“模拟冲突”会让远端协作者修改当前段落，并展示本页版本与远端版本，可选择保留任一方；“投审对账”内置可故障/恢复的模拟投审系统。
- 页面包含完整的示例论文、批注、回复、重复意见和两个历史版本。

## 技术栈

- React 19
- Vite + TypeScript
- Zustand
- Ant Design
- localStorage + 浏览器内模拟接口

## 本地开发

```bash
npm install
npm run dev
```

开发端口由 Vite 决定，源码不硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

## Docker

```bash
docker build -t sologsb-1002 .
docker run --rm -p 10002:80 sologsb-1002
```

容器内的 nginx 监听 `80`，访问 `http://localhost:10002`。
